# 🎯 寒假 C++ 学习计划（打牢基础版）

## 📅 总体安排

- **学习目标**：把 C++ 基础打牢，为日后 Python、ROS2、OpenCV 等提供坚实的代码基础。**不追求速度，追求掌握**。
- **每日时间**：**随学习内容与状态灵活调整**，建议单日 1～2.5 小时，以「当日小目标完成、有可见成果」为准，不必凑满固定时长。内容多时可分两天完成一个主题，状态好时可多做一点巩固。
- **节奏原则**：
  - **一个主题过关再进下一个**：每个主题都以「能独立写出、能讲清楚」为过关标准，过不了就加巩固日，不赶进度。
  - **学习日 + 巩固日**：重要主题安排「学习日」（理解+第一次写）和「巩固日」（不看书再写一遍或做小变体），确保真正记住。
- **内容不缩水**：计划覆盖从基础语法到 STL、现代 C++、模板入门与项目，只是把时间拉长、把每一步做实。

---

## ✨ 及时正反馈：怎样让自己有动力继续

学习过程中**看得见的进展**和**小成就**能持续带来动力，计划里已经按这一点做了设计。

### 1. 每个练习都是「有可见成果」的

- 写完代码**一运行就能看到结果**：计算器能算出数、词频统计能打印出前 N 个词、菜单能根据输入执行不同分支。
- 建议：每完成一个小练习，**立刻运行一次**，看到正确输出再停，这就是一次即时正反馈。

### 2. 用「小目标勾选」把进度可视化

每个主题下列了**可勾选的小目标**（□）。完成一项就勾一项，周末回看会很有成就感。例如：

- □ 看完本节理论 / 视频  
- □ 第一次按示例/提示写出代码并运行通过  
- □ **不看书、不查代码，独立再写一遍并运行通过**（巩固）  
- □ 能用自己的话讲清楚（给室友/自己录音都行）

你可以把「□」复制到自己的笔记或待办里，打勾保存。

### 3. 建议记录「今日完成」

每天结束时用一两句话记下：**今天完成了什么、运行出了什么结果**。例如：

- 「Day 1：计算器写完，加减乘除和除零提示都通过了。」
- 「巩固日：不看昨天代码，自己重写了一遍计算器，编译一次过。」

周末翻一翻，会清楚看到自己在推进，而不是「好像学了又好像没学」。

### 4. 每阶段结束的「你现在已经能…」

每个大阶段末尾有一句**「本阶段结束，你现在已经能…」**。用来提醒自己：**又掌握了一块实实在在的能力**，而不是在盲目赶进度。

## 📚 阶段一：基础巩固

**目标**：语法与基本结构过关，写小程序不卡壳，为后面 OOP 和 STL 打底。  
**建议**：每个子主题可占 **1～2 个学习日**，觉得不熟就加 **1 个巩固日**，不赶。

### 1.1 数据类型与变量

- **学习**：基本数据类型、类型转换、常量与变量作用域。
- **练习**：实现一个简单计算器（加减乘除，除零时给出提示即可）。
- **小目标**：□ 理论/笔记过一遍　□ 计算器写完并运行通过　□ 除零分支有处理　□ 巩固日：不看书独立重写一遍并运行通过
- **可见成果**：输入两个数和运算符，程序输出正确结果；输入除零时看到你的提示信息。

### 1.2 控制流

- **学习**：if/else、switch、for/while、break/continue。
- **练习**：九九乘法表 + 简单菜单（输入 1 退出、2 打印乘法表等）。
- **小目标**：□ 理论过一遍　□ 乘法表与菜单都能正确运行　□ 能口头解释每个分支在干什么　□ 巩固日：独立重写一遍
- **可见成果**：选择菜单项能看到对应输出；乘法表格式正确。

### 1.3 函数

- **学习**：函数重载、默认参数、值传递 vs 引用传递。
- **练习**：用重载写一组「打印/比较」函数；写一个带默认参数的函数并调用。
- **小目标**：□ 理论过一遍　□ 重载与默认参数都写出来并运行　□ 能说明「什么时候用值、什么时候用引用」　□ 巩固日：独立再写一遍
- **可见成果**：调用不同参数时能看到正确输出，且能解释传值/传引用的区别。

### 1.4 数组与指针

- **学习**：一维/二维数组、数组与指针关系、指针运算与越界风险。
- **练习**：矩阵加法（固定大小即可）；或「字符串长度/拷贝」小函数。
- **小目标**：□ 理论过一遍　□ 矩阵加法或字符串函数运行通过　□ 能画出一维数组和指针在内存中的关系　□ 巩固日：独立重写
- **可见成果**：输入两个矩阵能输出和；或输入字符串能输出长度/拷贝结果。

### 1.5 字符串

- **学习**：`std::string` 常用接口，与 C 风格字符串的简单对比。
- **练习**：字符串分割（按一个分隔符拆成若干子串，存到 `vector<string>`）。
- **小目标**：□ 理论过一遍　□ 分割函数写出来并在 main 里测几种情况　□ 巩固日：独立重写并多测几组输入
- **可见成果**：输入 "a,b,c" 和分隔符 ','，能输出 a、b、c 或类似结果。

### 1.6 结构体与枚举

- **学习**：结构体定义与使用、枚举的简单用法。
- **练习**：用结构体表示「学生」（姓名、学号、成绩），写输入/输出和按成绩排序（冒泡即可）。
- **小目标**：□ 理论过一遍　□ 程序能读入多个学生并按成绩排序输出　□ 能说明结构体传参用值还是引用、为什么　□ 巩固日：独立重写
- **可见成果**：输入几名学生的信息，程序按成绩排序并打印列表。

### 1.7 阶段一总结与小综合

- **复习**：过一遍类型、控制流、函数、数组/指针、字符串、结构体；整理易错点和常用写法。
- **小综合**：用结构体 + 函数 + 控制流，实现「简单通讯录」：添加、按姓名查找、打印全部（用数组或 vector 即可，不要求存文件）。
- **小目标**：□ 复习笔记/代码过一遍　□ 通讯录能添加、查找、打印并运行通过
- **本阶段结束，你现在已经能**：不查资料独立写出计算器、菜单、结构体排序和简单通讯录，并能口头解释关键逻辑。

## 🏗️ 阶段二：面向对象

**目标**：能设计简单类、理解构造/析构与 RAII、会用继承与多态，写出的代码结构清晰。  
**建议**：每个子主题 1～2 学习日 + 需要时 1 巩固日。

### 2.1 类的设计

- **学习**：封装、成员与访问控制、类的职责尽量单一。
- **练习**：设计并实现「银行账户」类：存款、取款、查余额，并做简单校验（如余额不为负）。
- **小目标**：□ 理论过一遍　□ 类写出来并能跑 1～2 个使用示例　□ 巩固日：独立重写
- **可见成果**：main 里创建账户、存款、取款、查余额，输出符合预期。

### 2.2 构造与析构、RAII

- **学习**：构造函数、析构函数、拷贝构造与深拷贝概念、RAII 思想。
- **练习**：写一个「资源管理」小类（如封装动态数组），在析构里释放；对比浅拷贝会导致的问题。
- **小目标**：□ 理论过一遍　□ 资源类写出来并能解释为什么要写析构/拷贝　□ 巩固日：独立重写并验证
- **可见成果**：程序运行结束无泄漏（可配合简单测试或打印验证析构被调用）。

### 2.3 继承与多态

- **学习**：继承、虚函数、override、基类指针/引用调用派生类方法。
- **练习**：设计「图形」基类 + 「圆」「矩形」派生，用虚函数求面积，在 main 里用基类指针统一调用。
- **小目标**：□ 理论过一遍　□ 继承体系写出来，多态调用结果正确　□ 能说明多态在这里的作用　□ 巩固日：独立重写
- **可见成果**：用基类指针指向圆/矩形，调用求面积得到正确数值。

### 2.4 运算符重载

- **学习**：运算符重载基本规则（如 +、==、<<），成员重载 vs 友元重载。
- **练习**：为「复数」类重载 +、-、<<（输出），并写一段测试代码。
- **小目标**：□ 理论过一遍　□ 复数运算与输出都正确　□ 巩固日：独立重写
- **可见成果**：两个复数相加、相减并 cout 输出，结果正确。

### 2.5 异常处理

- **学习**：try/catch/throw、异常安全的基本意识。
- **练习**：写「安全除法」：除零时抛异常，在 main 里 catch 并打印信息；可选：带异常处理的简单文件打开。
- **小目标**：□ 理论过一遍　□ 安全除法和 catch 能正确运行　□ 能说明何时用异常、何时用返回值　□ 巩固日：独立重写
- **可见成果**：除零时程序不崩溃，而是打印你的异常信息。

### 2.6 模板入门

- **学习**：函数模板（如 max<T>）、类模板基础（如 Stack<T>）。
- **练习**：写泛型 max(a,b) 模板；写简单 Stack<T>（push/pop/top，用 vector 或数组实现均可）。
- **小目标**：□ 理论过一遍　□ max 和 Stack 都能用 int、double、string 各测一次通过　□ 巩固日：独立重写
- **可见成果**：对 int、double、string 调用 max 和 Stack 操作，输出正确。

### 2.7 阶段二总结与小综合

- **复习**：类、构造/析构/RAII、继承/多态、运算符重载、异常、模板入门。
- **小综合**：用「继承 + 多态 + 异常」做一个小练习（如不同图形类 + 某处 try-catch 处理非法输入）。
- **小目标**：□ 复习过一遍　□ 小综合能运行并讲清楚各部分角色
- **本阶段结束，你现在已经能**：独立设计简单类、写带继承多态的代码、用异常处理错误、写简单函数/类模板，并能解释设计理由。

## 🚀 阶段三：STL 与现代 C++

**目标**：熟练用 vector/map、常用算法、智能指针，会用 Lambda 与移动语义，写出现代风格的 C++。  
**建议**：每个子主题 1～2 学习日 + 需要时 1 巩固日。

### 3.1 STL 容器

- **学习**：vector、map/unordered_map 常用接口，迭代器与范围 for。
- **练习**：用 vector + map 做「词频统计」：读入一段英文，按单词计数并输出前 N 个高频词。
- **小目标**：□ 理论过一遍　□ 词频统计能跑并输出前 N 个词　□ 能说明为什么用 vector/map　□ 巩固日：独立重写
- **可见成果**：输入一段英文，程序输出按出现次数排序的前 N 个单词及次数。

### 3.2 STL 算法

- **学习**：sort、find、transform 等常用算法，与迭代器配合。
- **练习**：用 sort + 自定义比较对结构体数组排序；用 find 在 vector 里查找。
- **小目标**：□ 理论过一遍　□ 排序和查找都运行正确　□ 能说出 sort 的大致复杂度（如 O(n log n)）　□ 巩固日：独立重写
- **可见成果**：对一组数据排序后输出；查找某元素并输出是否找到及位置。

### 3.3 智能指针

- **学习**：unique_ptr、shared_ptr 的用途与基本用法，循环引用与 weak_ptr 的直观理解。
- **练习**：用 unique_ptr 管理一个动态数组；用 shared_ptr 实现两对象共享某资源并写一小段演示。
- **小目标**：□ 理论过一遍　□ unique_ptr/shared_ptr 的示例都能跑　□ 能说明何时用 unique、何时用 shared　□ 巩固日：独立重写
- **可见成果**：程序正确运行且你能解释所有权归属。

### 3.4 Lambda 表达式

- **学习**：Lambda 语法、捕获列表、与 STL 算法配合。
- **练习**：用 lambda 配合 sort/find/transform 改写 3.2 的代码；写 2～3 个不同捕获方式的例子。
- **小目标**：□ 理论过一遍　□ 用 lambda 的版本能跑　□ 能解释值捕获和引用捕获的区别　□ 巩固日：独立重写
- **可见成果**：同样的排序/查找，用 lambda 写得更短、运行结果一致。

### 3.5 移动语义

- **学习**：左值/右值直观理解、右值引用 &&、移动构造与移动赋值的作用。
- **练习**：为一个「带动态资源的类」写移动构造和移动赋值，在 main 里用 std::move 触发并验证（可加打印或调试）。
- **小目标**：□ 理论过一遍　□ 移动构造/赋值写出来并能验证被调用　□ 能说明拷贝和移动在资源上的区别　□ 巩固日：独立重写
- **可见成果**：能通过打印或调试确认移动发生，资源没有重复释放。

### 3.6 现代 C++ 语法小结

- **学习**：auto、范围 for、统一初始化、nullptr，与前面内容的串联。
- **练习**：选一段之前写过的代码，用 auto、范围 for、列表初始化等做「现代风格」重写，功能不变。
- **小目标**：□ 理论过一遍　□ 重写后编译运行通过　□ 能指出改动的优点　□ 巩固日：再选一段代码做现代风格重写
- **可见成果**：代码更简洁，行为与原来一致。

### 3.7 阶段三总结与小综合

- **复习**：STL 容器/算法、智能指针、Lambda、移动语义、现代语法。
- **小综合**：用 STL + 智能指针 + Lambda 写一个小工具（如读文件统计行数/单词数，或简单过滤行）。
- **小目标**：□ 复习过一遍　□ 小工具能跑并达到预期效果
- **本阶段结束，你现在已经能**：独立用 STL 和现代 C++ 写小工具，能正确使用智能指针和 Lambda，并能解释移动语义在资源管理上的作用。

## 🔧 阶段四：模板进阶（会用级）与整体巩固

**目标**：能写常用模板、知道特化是什么，能在小项目里用上模板；不追求模板元编程。  
**建议**：每个子主题 1～2 学习日 + 需要时 1 巩固日；最后留 2～3 天整体复习。

### 4.1 模板基础深化

- **学习**：模板参数推导、模板重载、何时用模板何时用重载。
- **练习**：写泛型「打印容器」的模板函数（接受 vector/list）；写一个简单类模板并实例化几种类型。
- **小目标**：□ 理论过一遍　□ 模板函数和类模板都能跑　□ 能解释编译器如何推导类型　□ 巩固日：独立重写
- **可见成果**：对不同类型容器调用打印函数都能正确输出。

### 4.2 模板特化入门

- **学习**：全特化、偏特化的概念与简单写法；什么时候需要特化（如针对指针、string）。
- **练习**：为之前某个函数模板或类模板写一个全特化版本（如针对 const char* 或 std::string），并写测试。
- **小目标**：□ 理论过一遍　□ 特化版本能跑并看到特化被调用　□ 能说明特化在何时被调用　□ 巩固日：独立重写
- **可见成果**：用特化类型调用时，行为与泛型版本不同且符合预期。

### 4.3 模板练习与查漏补缺

- **练习**：把 4.1、4.2 的练习再写一遍或做小变体（如泛型「查找」函数 + 特化）；之前哪块不熟就多写几行。
- **小目标**：□ 至少完成一个变体并运行通过　□ 整理模板相关的易错点笔记

### 4.4 阶段四总结与整体复习

- **复习**：模板推导、重载、特化；与 STL、异常、OOP 的配合；整体过一遍 1～4 阶段知识点。
- **小综合**：用类模板 + 特化或函数模板 + 容器做一个小练习（如泛型栈 + 某类型的特化打印）。
- **小目标**：□ 小综合能跑并讲清楚模板在其中的作用　□ 整体知识过一遍，列出「还不太熟」的清单
- **本阶段结束，你现在已经能**：写函数模板/类模板并做特化，能在小项目里合理使用模板，并为下一阶段的小项目做好准备。

## 🎯 阶段五：小项目与总结

**目标**：做一个小而完整的项目，能跑、能讲、用上学过的特性；不追求代码量和高级特性堆砌。

### 5.1 项目选题与设计（建议 1～2 天）

- **选题建议**（任选或自拟，控制规模）：
  - 命令行小工具：待办列表、简单日记、本地词频/笔记统计。
  - 简单数据结构演示：用类封装链表/栈/队列，配合菜单做插入删除查询。
  - 小游戏逻辑：猜数字、简单文本冒险，用类组织状态与行为。
- **设计**：列出主要类/函数、数据如何存储、输入输出方式；能说清楚即可，不要求 UML。
- **小目标**：□ 选定题目　□ 设计写清楚（自己看得懂即可）

### 5.2 项目实现（建议 5～10 天，按需分配）

- **每日**：按模块实现、编译通过、简单自测；时间随内容调整，不必凑满 2 小时。
- **建议**：用到「类、STL、智能指针、异常、模板」中的至少几项；代码风格统一、适当注释。
- **不要求**：行数、复杂算法、网络/多线程。
- **小目标**：□ 核心功能能跑　□ 边界情况有简单测试　□ 自己重头编译一次能通过

### 5.3 项目收尾与自测（建议 1 天）

- 修 bug、补充 README（如何编译、如何运行、用了哪些 C++ 特性）。
- 自测：在另一台环境或重头 clone/编译一次，确保可复现。
- **小目标**：□ README 写清楚　□ 他人按 README 能跑（或自己换环境能跑）

### 5.4 学习总结与后续规划（建议 1～2 天）

- **总结**：这个寒假 C++ 学了什么、哪些已经能独立写、哪些还需后续加强；可以写成一页「学习总结」保存。
- **后续规划**：列出寒假后想学的内容（如 Python、ROS2、OpenCV），以及 C++ 上还想深化的点（如并发、更多模板、调试与性能）。
- **小目标**：□ 总结写下来　□ 后续规划列出来（哪怕只有几条）

**本阶段结束，你现在已经能**：独立完成一个小项目并说清楚用到的 C++ 特性，为日后继续学 Python 和机器人技术栈打下了扎实的代码基础。

## 🏆 学习成果检验（以「能写、能讲、能复现」为准）

- **阶段一**：能不查资料独立写出计算器、简单菜单、结构体排序和简单通讯录，并能口头解释关键逻辑。

- **阶段四**：能写函数模板/类模板并做一次特化，能讲清楚模板在项目里的作用。

## 💡 学习建议

1. **过关再往前**：每个主题都以「能独立写出、能讲清楚」为过关标准，过不了就加巩固日，不赶进度。
2. **每日可见成果**：每个练习都做到「运行出正确结果」再停，形成即时正反馈。
3. **记录「今日完成」**：每天一两句话记下完成了什么、运行出了什么，周末回看会有成就感。
4. **时间弹性**：单日 1～2.5 小时均可，内容多就分两天，状态好就多做巩固，计划可顺延。
5. **定期回顾**：每阶段结束重写一两个之前的练习，巩固「能写」的能力。

寒假把 C++ 基础打牢，后面学 Python、ROS2、OpenCV 会轻松很多。按自己的节奏来，稳比快重要。
