# 📺 C++ 视频观看顺序（与学习计划对齐）

## 🎯 使用说明

- 本顺序与《学习计划.md》（打牢基础版）**按阶段、按主题**对应：**学到某个主题时，再看对应视频**，然后立刻写代码巩固。
- **不要一次刷完**：以「能自己写出来」为准，视频为辅；先按计划动手，写不出或想加深理解时再补视频。
- **时间弹性**：计划不赶进度，视频也不必赶。标 **（选）** 的为选学；标 **（后期）** 的留到寒假之后再系统看。

## 💡 学习建议

1. **视频 + 立刻实践**：看完一个视频就写一段相关代码，能独立写出来再往下看。
2. **笔记**：记下每个视频里 1～3 个核心点，以及自己写过的示例代码路径，方便复习。
3. **巩固日可重看**：若某主题安排了巩固日，可在那天重看对应视频的要点，再独立写一遍代码。
4. **后期视频**：寒假结束后再按「模板进阶」「并发」等主题成块学习，并配合项目或课程使用。

寒假重点放在「能写、打牢基础」上，视频为理解服务，不追求数量。
